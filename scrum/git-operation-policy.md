## Git運用ルール

このリポジトリ（`.git` を含む）は管理者のパソコンにあり、Google Drive の外に置く。
メンバーに配布されるのは `.claude` `scrum` `CLAUDE.md` `README.md` の4つだけで、
`node scripts/publish.js <配布先フォルダ>` で Drive の共有フォルダへコピーされる。
メンバーは会社の制約で GitHub を使えず、`.git` を一切必要としない。

- git 操作（commit・push・ブランチ操作）は管理者のパソコン上でのみ行う
- メンバーは Drive の共有フォルダを Drive デスクトップ アプリで同期するだけでよい。
  git を操作する必要はない
- メンバー以外（管理者以外）が変更したい場合は、変更内容を管理者に共有し、
  管理者がコミットして再配布する
- `.claude` や `scrum` を更新したら、`scripts/publish.js` で再配布する。忘れると
  メンバーは古い内容のまま気づけないため、配布日時はダッシュボードの
  「配布日時」に表示される
