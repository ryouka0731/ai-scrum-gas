## Git運用ルール

このリポジトリは Google Drive の共有フォルダとして複数人に配布される。**git 操作は管理者のみが行う**。
Drive 同期フォルダ内で複数人が同時に git を回すと、Drive が競合コピー（`ファイル名 (competing copy).拡張子`）を
作ってしまい、リポジトリが壊れるため。管理者が1人で操作する場合も、commit 中の `.git` を
Drive が配りにいくため壊れることがある。

- メンバーはフォルダを Drive デスクトップ アプリで同期するだけでよく、git を操作する必要はない
- コミット・プッシュ・ブランチ操作は管理者のパソコン上でのみ行う
- 管理者以外が変更したい場合は、変更内容を管理者に共有し、管理者がコミットする

## リポジトリが壊れたときの復旧

`.git` が壊れた（`fatal: ...` が出る、競合コピーができた）場合は、管理者が Drive 同期フォルダの外で
リモートから clone し直し、`scrum/` などの作業内容を新しい clone へコピーしてから配置し直す。
壊れた `.git` を部分的に直そうとしないこと。
