# ai-scrum-gas

AI のチームメンバーと一緒にスクラム開発を進めるための仕組みです。
チームの状況は **Web アプリ**と**共有スプレッドシート**の2つで見られます。

## これは何をするもの？

スクラムの記録（やることリスト、進み具合、困りごと）は、このフォルダの中に
ファイルとして置かれています。それを自動で読み取って、Web アプリと共有スプレッドシートの
両方に組み立て直すのがこの仕組みです。ファイルを直接読む必要はありません。

- **PBI（やることの1件1件）の状態を変えたいとき**は、専用の Web アプリ（このチームのために
  用意された、ブラウザで開くページ）を使います
- **それ以外の、進み具合の確認**（ベロシティやバーンダウンなど）は、これまで通り
  共有スプレッドシートを開いて見ます

## どこで何を見る・操作するか

| したいこと | どこで | 操作 |
|---|---|---|
| PBI の状態を変える（New → Ready → In Progress など） | **Web アプリ**（カンバン） | カードをドラッグ、またはカードを開いてプルダウンで選ぶ |
| PBI を作成・編集・削除する | **Web アプリ**（カンバン） | 列の「追加」、またはカードを開く |
| 今どうなっているかを普段見る | **Web アプリ** | 見るだけ |
| ダッシュボード（スプリント目標、全体の進み具合） | 共有スプレッドシート | 見るだけ |
| バックログ（これからやることの一覧） | 共有スプレッドシート | 見るだけ |
| 完了バックログ（終わったこと） | 共有スプレッドシート | 見るだけ |
| ロードマップ（どの項目をどのスプリントでやるか） | 共有スプレッドシート | 見るだけ |
| ベロシティ（スプリントごとの推移） | 共有スプレッドシート | 見るだけ |
| バーンダウン（今のスプリントの残り） | 共有スプレッドシート | 見るだけ |
| 障害物（困っていること） | 共有スプレッドシート | 見るだけ（メモ列は書き込み可、後述） |
| 同期ログ（最後に読み込んだ時刻） | 共有スプレッドシート | 見るだけ |

**今のところ、Web アプリでできるのはカンバンでの操作（状態変更・PBI の作成・編集・削除）
だけです。** それ以外の情報はこれまで通りスプレッドシートにしかありません。この仕組みは
段階的に育てていく予定で、今後はダッシュボードなどの情報も少しずつ Web アプリ側へ
移していきます。今はその途中の状態だとご理解ください。

**スプレッドシートは「見るだけ」にしてください。** メモ列（後述）以外のセルを書き換えても、
次の更新（メニュー「AI Scrum」→「今すぐ同期」または30分ごとの自動更新）で元に戻ってしまいます。
内容を変えたいときは、後述の Web アプリを使うか、チームのスクラムイベントで相談してください。

## メンバーがやること

### 1. フォルダを自分のパソコンに取り込む

Google ドライブのデスクトップ アプリで、共有された Drive フォルダ（`.claude` `scrum` `CLAUDE.md` `README.md` が
入っています）を自分のパソコンに取り込みます。これで、自分のパソコンからフォルダの中身が見えるようになります
（後述の「同期」とは別の操作です）。

### 2. Web アプリを開く

チームの管理者から共有された Web アプリの URL を開きます。**PC のブラウザ**（Windows / Mac）で
開いてください。Firefox / Chrome / Edge / Safari のいずれでも動きます。

パスワードは必要ありませんが、**見るだけの人も含めて全員、Google アカウントでの
同意が必要です。** 詳しくは次の段落で説明します。

**スマホ・タブレットからも操作できます。** ただし指でのカードのドラッグには対応していないため、
状態を変えたいときはカードを開いて「ステータス」のプルダウンから選んでください。
作成・編集・削除はドラッグを使わないので、そのまま操作できます。

**はじめて開いたときだけ、確認画面が出ます。見るだけの人にも表示されます。**
この仕組みが自分の Google ドライブ全体を読み書きすることへの同意画面です。画面の案内に
沿って、自分のアカウントを選び、内容を確かめて「許可」を押してください。壊れたわけでは
ありません。2回目からは出ません。

なぜ「Drive 全体」なのか: この仕組みは名前でファイルを探して読み書きするため
（`scrum/product_backlog.csv` など）、アプリが作成したファイルしか開けない
限定的な権限では動きません。カンバンを開くだけでも、この広い権限への同意が
必要になります。

以前から使っている方は、今回から**求められる権限が変わりました**（ドライブの読み取りだけでなく、
書き込みも求めます。理由は次の「カンバンで状態を変える」をご覧ください）。そのため、
**もう一度この確認画面が出ます。**同じ手順で「許可」を押してください。

### 3. カンバンで PBI を操作する

Web アプリには、PBI を「New」「Ready」「In Progress」「Review」「Done」の
列に並べたカンバン（付箋を貼った board のようなもの）が表示されます。

**状態を変える**: カードを別の列へ**ドラッグ&ドロップ**するか、カードを開いて
「ステータス」のプルダウンで選んで保存します。

**新しく作る**: 列の上にある「追加」から開きます。その列のステータスで作られるので、
あとからステータスを選び直す必要はありません。

**編集する**: カードをクリックすると詳細パネルが開きます。パネルを開いたままでも
別のカードをドラッグできます（画面は覆われません）。

**削除する**: パネルの「削除」を押すと、確認なしでその場で消えます。消した直後に
画面下へ出る通知の「取り消す」を押すと、元の ID のまま戻せます（通知は10秒で消えます）。
**終わった PBI は削除ではなく Done 列へ移してください。** 削除は「間違って作った」場合の
操作です。

これらの変更は元のファイル（`scrum/product_backlog.csv`）にもすぐに反映されます。

**ただし、共有スプレッドシート側の見た目がすぐに変わるわけではありません。**
スプレッドシートは、これまで通りメニュー「AI Scrum」→「今すぐ同期」または30分ごとの
自動更新のタイミングで作り直されます。Web アプリだけを見ていれば変更はすぐに反映されて
見えるので、通常は気にする必要はありません。

**他の人（または、パソコンで動いている Claude Code）が先に同じカードを変えていた場合**、
「他の変更が先に入っています」という案内が表示され、画面が最新の内容に更新されます。
その場合は、あらためて操作をやり直してください。

## スプレッドシートに書き込んでいいの？

**「メモ」列だけ書き込めます。** バックログと障害物のシートにある一番右の列です。
ここに書いたことは、**その項目が一覧に残っている限り**、次の更新でも引き継がれます。

ただし、項目が「完了バックログ」へ移るとメモ列が無くなるため、そのメモは残りません。
元のファイル側から項目が消えた場合も同じです。長く残したい内容は、スクラムイベントで
ファイル側に書き移してください。

それ以外のセルに書いても、次の更新で消えてしまいます。内容を変えたいときは、
PBI の状態であれば Web アプリのカンバンを使い、それ以外はチームのスクラムイベントで相談してください。

## プロダクトオーナーに相談したいとき

バックログの「メモ」列に相談内容を書いておきます。
そのうえで、パソコンで Claude Code を開き、次のように入力します。

```
/ask-to-po-shuri
```

プロダクトオーナー役の AI が相談に答えます。

## Claude Code の使いかた（はじめての人向け）

先ほどの `/ask-to-po-shuri` のように、スクラムのイベントを自分で進めたいときは
Claude Code というツールを使います。文章で指示すると作業してくれるツールです。
パソコンにまだ入っていない場合は、チームの管理者にインストールを依頼してください。

まず、手順1で取り込んだ Google ドライブの共有フォルダ（`.claude` `scrum` `CLAUDE.md` `README.md` が
入っています）をパソコンで開いておきます。Mac の方は Finder（デスクトップ下のドック、またはメニューバー右上の
虫めがねから開けるアプリで、ファイルの一覧を見るためのもの）の左側の一覧に
「Google Drive」が出ています。Windows の方はエクスプローラー（画面下のタスクバーにある
フォルダのアイコンで、ファイルの一覧を見るためのアプリ）の左側の一覧に「Google Drive」が出ています。

**Mac の方**

1. ターミナル（文字だけで操作する黒い画面のアプリ。Launchpad や Spotlight 検索から開けます）を開きます
2. `cd` と入力してスペースを1つ入れます（Enter はまだ押しません）。続けて Finder で
   その共有フォルダを探し、その場所からターミナルの画面へドラッグ＆ドロップします。
   フォルダのパスが自動で入力されるので、そこで Enter を押します
3. `claude` と入力して Enter を押します
4. あとは日本語で話しかけるだけです

**Windows の方**

1. 「Windows ターミナル」（無ければ「PowerShell」でも構いません。どちらも文字だけで操作する画面で、
   スタートメニューの検索から開けます）を開きます
2. `cd ` と入力してスペースを1つ入れます（Enter はまだ押しません）。続けてエクスプローラーで
   その共有フォルダを探し、その場所からターミナルの画面へドラッグ＆ドロップします。
   フォルダのパスが自動で入力されるので、そこで Enter を押します
3. `claude` と入力して Enter を押します
4. あとは日本語で話しかけるだけです

スクラムのイベントは、次のように `/` から始まる短い言葉で呼び出せます。

| 入力する言葉 | 何が起きるか |
|---|---|
| `/backlog-refinement` | やることリストを整理する |
| `/sprint-planning` | スプリントの計画を立てる |
| `/one-day-in-scrum` | 1日分の作業を進める |
| `/sprint-review` | できたものを確認する |
| `/sprint-retrospective` | ふりかえりをする |

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| Web アプリの内容が古い気がする | 画面右上の「最新にする」を押す |
| カードをドラッグしても動かない | スマホ・タブレットはドラッグに対応していません。カードを開いてプルダウンから状態を選んでください |
| 削除した PBI を元に戻したい | 削除直後に画面下へ出る通知の「取り消す」を押してください。10秒で通知は消え、以降は戻せません |
| ドラッグしたのに元の場所に戻ってしまう | 画面に出るメッセージを確認してください。「他の変更が先に入っています」なら、最新の内容になっているので操作をやり直してください |
| Web アプリの変更がスプレッドシートに出てこない | すぐには反映されません。メニュー「AI Scrum」→「今すぐ同期」を押すか、30分待ってください |
| バックログが空っぽ | まだ内容が入っていません。`/backlog-refinement` で作ります |
| メニュー「AI Scrum」が出ない | スプレッドシートを開き直してください |
| `/backlog-refinement` などのイベントが古い手順で動く | 「ダッシュボード」シートの「配布日時」を確認する。かなり前の日時なら `.claude` が更新されていない可能性があるので、管理者に連絡する |

## 困ったら

「同期ログ」シートの内容を添えて、チームの管理者に相談してください。
